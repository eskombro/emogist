# emogist training dataset

3,000 English and French everyday sentences, each paired with an AI-generated emoji sentence that keeps its gist.

# Main features and functionalities

- **Balanced:** 1,500 examples per language, half real and half AI-generated.
- **Real sentences** from Tatoeba, with author and sentence ID kept for attribution.
- **AI sentences** written directly in each language, including a pattern for exact numbers.
- **Emoji labels** from one teacher model and one prompt version, all passing automatic format checks.

# Main parts of the project

| Path | Purpose |

| `train.jsonl` | The dataset, one JSON example per line |

## Fields

| Field | Meaning |
|---|---|
| `id` | Example ID. Real IDs follow the pool; AI IDs start with `ai-` |
| `lang` | `en` or `fr` |
| `source` | `real` or `ai` |
| `pattern` | AI sentence pattern: speech, past, future, mishap, moment or numbers. Empty for real sentences |
| `author` | Tatoeba contributor. Empty for AI sentences |
| `generator` | Model that wrote the AI sentence. Empty for real sentences |
| `sentence` | The input sentence |
| `emojis` | The emoji sentence |
| `teacher` | Model that wrote the label |
| `prompt` | Labelling prompt version and worksheet hash |

## How it was made

1. Real sentences were filtered by plain rules and shuffled once with a fixed seed.
2. AI sentences came from a grid of topics, patterns, feelings, lengths and speakers. Blocklist, format and near-duplicate checks applied to all of them.
3. The teacher labelled 3,310 sentences, with one retry on failure. 3,150 labels passed the format and convention checks.
4. The first valid labels in pool order filled each quota.

No sentence overlaps exactly with the dev or test sets.

## Limitations

- Automatic checks verify **format, not meaning**, so a valid label can still be poor.
- Human review was an **informal read** of part of a 120-example sample plus its numbers rows. It produced no quality score.
- One Tatoeba contributor wrote 384 of the 1,500 real sentences, so their style is overrepresented.
- Real and AI sentences differ in length and style.
- The numbers check is a simple word and digit rule. It can accept words like French "neuf" (new) and misses "one", "une", "thousand" and "mille".
- Each keycap digit counts toward the 10-emoji limit, so number-heavy sentences were dropped more often and the numbers examples lean simpler.
- The blocklist is simple, so it can miss unsuitable sentences and remove harmless ones.
