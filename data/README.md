# Data

## `test_sentences.csv`: fixed test set

- 100 everyday sentences: 50 French (`fr-01`…`fr-50`) and 50 English (`en-01`…`en-50`). Columns: `id`, `lang`, `sentence`, `tags` (`time` and `speech` mark sentences used to check those emoji rules).
- Used **only for evaluation**, never for training. Few-shot examples and training data deliberately avoid its topics.
- Covers different lengths, negation, past/future, numbers, speech, humour and roles.
- The first 10 sentences per language are the original manual test set; the rest were added to get more reliable comparisons.

**AI disclosure:** most sentences were drafted with Claude (Anthropic) and reviewed by the author. They are used as evaluation inputs only, not as training data.

## Training dataset

Built in [step 3](../03_dataset/): 3,000 sentences, half real (Tatoeba, CC BY 2.0 FR) and half AI-generated, written natively in English and French. Labels are AI-generated by DeepSeek V4.1 Flash. See the [dataset card](../03_dataset/full/README.md).

This test set was used to compare and shortlist the student and teacher models in steps 1 and 2, so the final result may be slightly optimistic. It was never used for training or prompt tuning. Prompt and pilot comparisons use a separate set of 100 real sentences, [`real_dev.csv`](../03_dataset/sentences/real_dev.csv).
